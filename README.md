# RepoCleaner - AI 驱动的 GitHub 仓库清理工具

智能分析您的 Fork 仓库和原创项目，帮助您保持 GitHub 仓库整洁。

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GLM_API_KEY` in [.env.local](.env.local) to your GLM API key (从 https://open.bigmodel.cn/ 获取)
3. Run the app:
   `npm run dev`
